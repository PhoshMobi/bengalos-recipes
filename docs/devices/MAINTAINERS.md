# Device Maintainers

Each BengalOS device has one (ideally more) maintainers that care about the
functionality.

## Phones

We consider a phone supported when it has

- Display panel / touch
- Suspend/Resume
- GPU acceleration
- Audio & Call audio
- Bluetooth A2DP profile support
- Front- and back cameras
- Haptic
- Camera flash (if present)
- Status LED (if present)
- SD Card (if present)

only then should we mention it in the device's docs as supported and
mention it in the image downloads.
