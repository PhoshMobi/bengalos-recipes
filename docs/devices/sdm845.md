# Qualcomm SDM845 based phones

*Support for SDM845 is experimental, make sure to check the open issues*

Supported devices

- Google Pixel 3 (google,blueline)
- SHIFT6mq (shift,axolotl)
- onePlus6 (oneplus,enchilada)

### Flashing U-Boot

First we need to flash U-Boot to the slot you want to use. You can fetch a prebuilt
u-boot for your device from the [tauchgang project][tauchgang]. E.g. for the Google Pixel 3:

```sh
sudo apt install fastboot
fastboot flash boot_a u-boot-google-blueline.img
```

### Flash the BengalOS Image

After flashing U-Boot to the board we can build and flash the image:

```sh
make bengalos-sdm845-immutable
fastboot erase dtbo
fastboot -S 100M flash userdata build-sdm845-immutable/BengalOS_<version>.img
fastboot reboot
```

#### SHIFT6mq

For the SHIFT6mq you need an updated ABL that will be distributed via LVFS as otherwise
you won't be able to enter fastboot anymore via `Power+Vol-` (Fastboot via Recovery (`Power+Vol+`
still works).

##### Firmware upgrades

```sh
fwupd get-updates
fwupd update
```
